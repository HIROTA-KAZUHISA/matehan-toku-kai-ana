## 分析方法

- ツール: Claude Vision（Read tool）による画像認識
- 入力: XDWファイルをPNGに変換した画像（635枚）
- ZZ番号: ZZ-XXXX 形式のみ対象（S-XXXX, ZK-XXX 等は「なし」）
- 担当者特定: ファイル名「(XXXさん対応中)」を最優先とし、手書き宛名「技術 〇〇様」で補完
