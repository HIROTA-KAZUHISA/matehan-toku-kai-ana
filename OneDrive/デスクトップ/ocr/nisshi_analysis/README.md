### result.tsv の列定義

| 列 | 説明 |
|----|------|
| idx | 連番（0000〜0488） |
| filename | 元のXDWファイル名 |
| num_pages | ページ数 |
| category | 誤記 / 誤記（記載漏れ含む） / 仕様変更依頼 / その他 |
| zz_num | ZZ-XXXX 形式の番号（なければ「なし」） |
| machine | 機種コード |
| requester | 依頼者（工場側） |
| recipient | 担当者（技術部側） |
| summary | 内容の要約 |

## 分析方法

- ツール: Claude Vision（Read tool）による画像認識
- 入力: XDWファイルをPNGに変換した画像（635枚）
- ZZ番号: ZZ-XXXX 形式のみ対象（S-XXXX, ZK-XXX 等は「なし」）
- 担当者特定: ファイル名「(XXXさん対応中)」を最優先とし、手書き宛名「技術 〇〇様」で補完
- 前川TL宛の作図者特定: PaddleOCR（Python 3.12）で表題欄を読み取り実担当者へ振り分け
